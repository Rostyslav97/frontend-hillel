Цикли в JavaScript

                Цикли в JavaScript:

                Цикли в JavaScript - це конструкції, які дозволяють виконувати одні й ті самі дії або блок коду декілька
                разів. Це допомагає автоматизувати виконання повторюваних завдань у вашій програмі. У JavaScript існують
                різні типи циклів, такі як "for", "while", "do-while", "for...in" та "for...of".

                Цикл "for" використовується для визначеного кількості ітерацій, цикл "while" - для виконання дій, доки
                задана умова є істинною, а цикл "do-while" виконується принаймні один раз і потім перевіряє умову.

                Цикли "for...in" та "for...of" дозволяють перебирати властивості об'єктів або елементи масиву відповідно.

                Цикли є важливим елементом програмування, і з їх допомогою ви можете створити багато різноманітних
                алгоритмів та розв'язати завдання у вашому програмному коді.
