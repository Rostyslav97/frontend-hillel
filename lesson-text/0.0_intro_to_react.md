# Що таке React ?

React - це бібліотека для створення користувацьких інтерфейсів, принаймні, так характеризують її розробники.
[Репозиторій на GitHub](https://github.com/facebook/react)

React став таким успішним тому що на момент створення дуже сильно знизив складність вирішуваних завдань, була спрощена
робота з DOM, а також він сам по собі був простіше ніж інші фреймворки створені на момент його виходу в 2013 році.

Оскільки React є бібліотекою його можна вбудовувати вже в існуючий проект там де це потрібно. Але також
React може взяти на себе повне управління фронтендом розроблюваного проекту. У такому випадку потрібно буде доповнити
бібліотеку доповненнями, які беруть на себе завдання по навігації та управлінню станом даних (react-router і redux).

Окрім фронтенду React також можна використовувати на сервері (SSR - server-side rendering) і для розробки під мобільні
платформи (React Native).

## Bootstrap

Для виконання домашніх завдань ми будемо використовувати фреймворк Bootstrap. Якщо ви ще не знайомі з ним, то прочитайте
керівництво по [Бутстрапу](https://getbootstrap.com/).

## create-react-app

Розробники у Facebook, розуміючи як складно налаштувати з нуля екосистему для старту фронтенд-проектів, створили проект
під назвою create-react-app. Це npm-бібліотека, яка дозволяє стартувати з нульовою конфігурацією.

```
npx create-react-app my-app
cd my-app/
npm start
```

#### Встановлення

- Створюємо папку з проектом
- Переходимо в неї та відкриваємо консоль
- Виконуємо команду: ```npx create-react-app [назва вашого проекту]```
- Чекаємо поки все встановиться
- Після встановлення переходимо в створену папку: ```cd [назва вашого проекту]```
- Виконуємо команду: ```npm start```
- Далі відкриваємо localhost:3000 і працюємо.

### Відлагодження
Оскільки React працює на фронтенді, то й помилки будуть з'являтися там само. Не забувайте завжди тримати відкритою
консоль (наприклад, у інструментах розробника Chrome) і уважно читати все, що там написано. Більша частина помилок
буде виводитися саме там.

Також не забудьте встановити
[React Developer Tools](https://chrome.google.com/webstore/detail/react-developer-tools/fmkadmapgofadopljbjfkapdkoienihi?hl=ru).
Це розширення для браузера, яке дає дуже зручну панель для
аналізу відбуваючого з React у вашому додатку. Почніть його використовувати з першого уроку.
