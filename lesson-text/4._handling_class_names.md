# Обробка імен класів

Інтерактивні елементи UI мають більше одного стану відображення. Наприклад, модальне вікно може бути відкрите або
закрите, а перемикач увімкнений або вимкнений. Загальноприйнято змінювати ці стани класами.

Працюючи безпосередньо з DOM, можна використовувати `classList`, який містить зручні методи для додавання та видалення
класів. У React "з коробки" немає жодних зручностей. Властивість `className` — це всього лише рядок, а рядки незручні
для обробки.

> lesson-files/handling_class_names/src/components/Button.jsx;

```jsx
// Button.jsx

import React from "react";

class Button extends React.Component {
    render () {
        const { isPressed, isHovered, label } = this.props;
        let btnClass = 'btn';
        if (isPressed) {
            // Треба конкатенувати класи
            btnClass += ' btn-pressed';
        } else if (isHovered) {
            btnClass += ' btn-over';
        }
        return <button className={btnClass}>{label}</button>;
    }
};

export default Button;
```

Для вирішення цієї задачі творці React рекомендують використовувати пакет `classnames`. Принцип його роботи простий: 
замість маніпулювання рядком безпосередньо, потрібно сформувати правильний об'єкт, який вже буде перетворений у рядок.

> lesson-files/examples/src/components/ButtonCN.jsx

```jsx
// ButtonCN.jsx

import React from "react";
import cn from 'classnames';

class ButtonCN extends React.Component {
    render() {
        const { isPressed, isHovered, label } = this.props;
        // значення це true або false. Якщо значення true, то клас буде включений,
        // якщо false – то ні
        // 'btn' це клас, який буде підставлений у будь-якому випадку
        const btnClass = cn('btn', {
            'btn-pressed': isPressed,
            'btn-over': !isPressed && isHovered,
        });
        return <button className={btnClass}>{label}</button>;
    }
}
export default ButtonCN;

```

Підставимо конкретні значення:

```js
const btnClass = cn('btn', {
'btn-pressed': false,
'btn-over': true,
});

console.log(btnClass); // 'btn btn-over'
```

Функція cn() побудована так, що вона приймає на вхід будь-яку кількість аргументів. Якщо аргумент має `string` 
тип, то він вважається обов'язковим класом. Якщо це об'єкт – то тоді працює логіка, описана вище.

```js
const btnClass = cn('btn', 'another-class', {
  'btn-pressed': isPressed,
  'btn-over': !isPressed && isHovered,
});
```

Обов'язкові класи можна задавати і в самому об'єкті:

```js
const btnClass = cn({
  'btn something-else': true,
  'btn-pressed': isPressed,
  'btn-over': !isPressed && isHovered,
});
```

Іноді ім'я класу генерується динамічно, тоді можна використовувати наступний код:

```js
const buttonType = 'primary';
const btnClass = cn('btn', `btn-${buttonType}`);
console.log(btnClass); // 'btn btn-primary'
// Або те ж саме
// const btnClass = cn('btn', {
//   [`btn-${buttonType}`]: true
// });
```
