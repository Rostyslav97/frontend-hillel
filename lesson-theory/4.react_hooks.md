# React Hooks

Хуків існує велика кількість, але зараз ми поговоримо про основні з них.
Переглянути повну документацію по хукам ви можете за посиланням:
> https://react.dev/reference/react/hooks

**React Hooks** (хуки) — це функції, які дозволяють використовувати стан (state) та інші можливості React
(наприклад, методи життєвого циклу) у функціональних компонентах. Вони були введені в React версії 16.8 і 
зробили функціональні компоненти повноцінною заміною класових.

## Чому з’явилися хуки?

До появи хуків функціональні компоненти не мали можливості працювати зі станом або методами життєвого циклу. Для
цього потрібно було використовувати класові компоненти. Хуки вирішують кілька важливих проблем:
1.	Управління станом у функціональних компонентах.
2.	Зменшення коду та покращення читабельності.
3.	Повторне використання логіки через кастомні хуки.
4.	Відмова від класів, що спрощує навчання React.


## Основні хуки

**1. useState**
Дозволяє додати стан у функціональний компонент.

>lesson-files/react_hooks/src/components/Counter.jsx

```js
const [state, setState] = useState(initialState);
```
•	state — поточний стан.
•	setState — функція для його оновлення.
•	initialState — початкове значення стану.
```js
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}
```


**2. useEffect**
Дозволяє виконувати побічні ефекти у функціональних компонентах.

>lesson-files/react_hooks/src/components/Timer.jsx

```js
useEffect(() => {
  // Код ефекту
  return () => {
    // Очищення ефекту (опціонально)
  };
}, [dependencies]);
```
•	Ефект виконується після кожного рендера компонента (за замовчуванням).
•	Масив залежностей визначає, коли саме викликати ефект.
```js
import React, { useState, useEffect } from 'react';

function Timer() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    const interval = setInterval(() => {
      setSeconds((prev) => prev + 1);
    }, 1000);

    return () => clearInterval(interval); // Очищення інтервалу
  }, []); // Викликається один раз після монтування

  return <p>Time: {seconds}s</p>;
}
```


**3. useContext**
Дозволяє використовувати контекст у функціональних компонентах.

>lesson-files/react_hooks/src/components/ThemedButton.jsx

```js
const value = useContext(Context);
```
```js
import React, { useContext } from 'react';

export const ThemeContext = React.createContext('light'); // Експорт контексту

function ThemedButton() {
	const theme = useContext(ThemeContext); // Використання контексту

	return (
			<button
					style={{
						background: theme === 'light' ? '#fdfdfd' : '#7a1313',
						color: theme === 'light' ? '#000' : '#fff',
						border: '1px solid',
						padding: '10px 20px',
						margin: '10px',
						cursor: 'pointer',
					}}
			>
				Themed Button
			</button>
	);
}

export default ThemedButton;
```


**4. useReducer**
Аналог Redux для локального стану. Використовується для роботи зі складним станом.

>lesson-files/react_hooks/src/components/CounterV2.jsx

```js
const [state, dispatch] = useReducer(reducer, initialState);
```
•	reducer — функція, яка описує, як змінюється стан.
•	dispatch — функція для виклику дій (actions).
•	initialState — початковий стан.
```js
import React, { useReducer } from 'react';

function reducer(state, action) {
  switch (action.type) {
    case 'increment':
      return { count: state.count + 1 };
    case 'decrement':
      return { count: state.count - 1 };
    default:
      return state;
  }
}

function CounterV2() {
  const [state, dispatch] = useReducer(reducer, { count: 0 });

  return (
    <div>
      <p>Count: {state.count}</p>
      <button onClick={() => dispatch({ type: 'increment' })}>+</button>
      <button onClick={() => dispatch({ type: 'decrement' })}>-</button>
    </div>
  );
}
```


## Додаткові хуки

**1. useMemo**
Оптимізує виконання обчислень, запам’ятовуючи результат.
```js
const expensiveCalculation = useMemo(() => {
  return computeSomething(largeData);
}, [largeData]);
```

**2. useCallback**
Запам’ятовує функцію, щоб вона не створювалась заново при кожному рендері.
```js
const handleClick = useCallback(() => {
  console.log('Button clicked');
}, []);
```

**3. useRef**
Дозволяє зберігати значення між рендерами або отримувати доступ до DOM-елементів.

>lesson-files/react_hooks/src/components/InputFocus.jsx

```js
import React, { useRef } from 'react';

function InputFocus() {
  const inputRef = useRef();

  return (
    <div>
      <input ref={inputRef} />
      <button onClick={() => inputRef.current.focus()}>Focus</button>
    </div>
  );
}
```


## Правила використання хуків
1.	Викликайте хуки тільки на верхньому рівні.
	•	Не викликайте хуки всередині умов або циклів.
2.	Використовуйте хуки тільки в React-компонентах або інших хуках.
