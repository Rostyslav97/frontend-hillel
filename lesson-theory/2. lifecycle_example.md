## 1. Монтування (Mounting)
Монтування — це процес створення компонента та його відображення у DOM.
> lesson-files/examples/src/components/MyMountingComponent.jsx

Методи:
1.	constructor
2.	static getDerivedStateFromProps
3.	render
4.	componentDidMount
```js
class MyMountingComponent extends React.Component {
  constructor(props) {
    super(props); // Ініціалізація пропсів
    this.state = { data: null }; // Встановлення початкового стану
    console.log('Constructor');
  }

  static getDerivedStateFromProps(props, state) {
    console.log('getDerivedStateFromProps');
    return null; // Повертає новий стан або null
  }

  componentDidMount() {
    console.log('componentDidMount');
    // Ідеальне місце для запитів до API
    fetch('/api/data')
      .then((response) => response.json())
      .then((data) => this.setState({ data }));
  }

  render() {
    console.log('Render');
    return <div>{this.state.data ? this.state.data : 'Loading...'}</div>;
  }
}
```


## 2. Оновлення (Updating)
Оновлення компонента відбувається, коли змінюються пропси або стан.
> lesson-files/examples/src/components/MyUnmountingComponent.jsx

Методи:
1.	static getDerivedStateFromProps
2.	shouldComponentUpdate
3.	render
4.	getSnapshotBeforeUpdate
5.	componentDidUpdate
```js
class MyUpdatingComponent extends React.Component {
  constructor(props) {
    super(props);
    this.state = { counter: 0 };
  }

  static getDerivedStateFromProps(props, state) {
    console.log('getDerivedStateFromProps');
    return null; // Повертає новий стан або null
  }

  shouldComponentUpdate(nextProps, nextState) {
    console.log('shouldComponentUpdate');
    return true; // Визначає, чи потрібно перерендерити компонент
  }

  getSnapshotBeforeUpdate(prevProps, prevState) {
    console.log('getSnapshotBeforeUpdate');
    return null; // Може повернути значення, яке передасться у componentDidUpdate
  }

  componentDidUpdate(prevProps, prevState, snapshot) {
    console.log('componentDidUpdate');
    // Викликається після оновлення компонента
  }

  increment = () => {
    this.setState((prevState) => ({ counter: prevState.counter + 1 }));
  };

  render() {
    console.log('Render');
    return (
      <div>
        <p>Counter: {this.state.counter}</p>
        <button onClick={this.increment}>Increment</button>
      </div>
    );
  }
}
```


## 3. Розмонтування (Unmounting)
Розмонтування відбувається, коли компонент видаляється з DOM.
> lesson-files/examples/src/components/MyUnmountingComponent.jsx

Метод:
•	componentWillUnmount
```js
class MyUnmountingComponent extends React.Component {
  componentWillUnmount() {
    console.log('componentWillUnmount');
    // Ідеальне місце для очищення ресурсів, таких як таймери, інтервали або підписки
  }

  render() {
    return <div>Goodbye!</div>;
  }
}
```
